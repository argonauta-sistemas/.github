# Seguridad

Si encuentras un problema de seguridad en alguno de nuestros sistemas (por
ejemplo, datos de una persona visibles para quien no debería verlos), **no lo
publiques en un issue**. Escríbenos a **argonautasistemas@gmail.com** con:

- qué sistema y qué dirección,
- qué se puede ver o hacer,
- los pasos para reproducirlo, sin usar ni guardar datos de terceros.

Respondemos dentro de las 48 horas. Si el problema afecta datos personales,
avisamos al cliente dueño de esos datos, como dice nuestro acuerdo de
servicio.
